# Metra 0.5.18

## English

- Address the remaining Windows startup bubble distortion by explicitly setting the minimum window size and synchronizing the WebView size when the bubble is shown.
- Extend native startup checks to verify the WebView viewport and rendered bubble dimensions before mouse interaction.

### Windows x64

Run the installer to upgrade, or use the portable EXE with WebView2 installed.

### macOS installation

Move Metra to Applications. Before launching it for the first time, run this command to remove the quarantine attribute:

```sh
sudo xattr -dr com.apple.quarantine /Applications/Metra.app
```

## 中文

- 针对 Windows 首次启动仍出现悬浮球拉伸的问题，显式设置最小窗口尺寸，并在显示悬浮球时同步 WebView 尺寸。
- 扩展原生启动检查，在鼠标交互前验证 WebView 视口及悬浮球实际渲染尺寸。

### Windows x64

运行安装包即可升级，也可使用便携 EXE，需已安装 WebView2。

### macOS 安装

将 Metra 移入 Applications 后，首次启动前执行以下命令以移除隔离标记：

```sh
sudo xattr -dr com.apple.quarantine /Applications/Metra.app
```
