# Metra 0.5.16

## English

- Restore exact Cursor usage on Windows when Cursor encrypts its desktop sign-in token. Metra reads the local data in read-only mode and uses Windows DPAPI under the current Windows account.
- Keep the confirmed sign-in state and the last successful usage reading if decryption fails. Metra shows the cause of the refresh failure and still prompts for sign-in when the session expires.

### Windows x64

Run the installer to upgrade or use the portable EXE with WebView2 installed. Enable **Cursor compatibility** in Metra settings to read exact usage.

### macOS installation

Move Metra to Applications. Before launching it for the first time, run the following command to remove the quarantine attribute.

```sh
sudo xattr -dr com.apple.quarantine /Applications/Metra.app
```

## 中文

- 修复 Cursor 桌面版加密登录令牌后，Metra 在 Windows 上无法读取精确用量的问题。Metra 以只读方式访问本地数据，并使用当前 Windows 账户的 DPAPI 解密。
- 解密失败时保留已确认的登录状态和上次成功读取的用量，并显示刷新失败的原因。会话确实失效时，仍会提示重新登录。

### Windows x64

运行安装包即可升级。也可直接使用便携 EXE，需已安装 WebView2。在 Metra 设置中开启 **Cursor 兼容模式** 即可读取精确用量。

### macOS 安装

将 Metra 移入 Applications 后，首次启动前运行以下命令来移除隔离标记。

```sh
sudo xattr -dr com.apple.quarantine /Applications/Metra.app
```
