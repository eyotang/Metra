# Metra 0.5.11

- 修复详情面板关闭或失焦后，悬浮球／吸边胶囊仍显示旧用量、需要鼠标移入才更新的问题。可见性通知只由对应窗口接收，避免面板的隐藏事件暂停悬浮窗口渲染。
- 保留全局共享用量、逐服务刷新、隐藏窗口缓存数据及重新显示时补画最新值的行为。不增加轮询或持续重绘，不改变采集周期、默认悬浮球和已有状态栏功能。
- 补充跨窗口可见性隔离的 Chromium/WebKit 回归测试，并加入原生胶囊退到后台静置 330 秒后无需悬停即可更新的 CI 验收。

---

Fix stale bubble and docked-capsule usage after the details panel closes or loses focus. Visibility listeners now target their own window, so panel hide events cannot pause a visible capsule or resume a hidden one. Shared usage updates, refresh intervals, hidden-window caching, the default bubble mode and existing status-bar behavior remain unchanged. No polling or continuous redraw is added.

Add Chromium/WebKit coverage for cross-window visibility isolation and a native macOS CI check that updates a collapsed capsule after 330 seconds in the background without hovering or expanding it.
