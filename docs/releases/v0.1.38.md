# Metra 0.1.38

## English

### Changes

- Add automatic edge docking: releasing the bubble at a screen edge immediately half-hides it without waiting for idle.
- Automatically detect the interface language and save a choice of Simplified Chinese, English, Japanese or Korean.
- Add README editions in those four languages.
- Fix unresponsive Windows bubble clicks and add real-click regression checks.
- Improve language-selector alignment, width and menu colors on Windows.
- Improve Cursor compatibility, CLI rescanning and translated copy.
- Improve macOS Universal and Windows Portable builds; remove sccache and fix pnpm workspace configuration.

### Downloads

- `Metra_0.1.38_universal.dmg`: macOS Universal, Apple Silicon and Intel.
- `Metra-0.1.38-portable.exe`: Windows x64 portable.

### Signing

> [!WARNING]
> The macOS app/DMG is not Developer ID signed or Apple-notarized. Windows executables are not Authenticode signed. Gatekeeper or SmartScreen may block or warn on launch. Download only from this GitHub Release and verify the SHA-256 checksums.

### macOS installation

Copy Metra.app to Applications, then run this command to remove the quarantine attribute recursively:

```sh
sudo xattr -dr com.apple.quarantine /Applications/Metra.app
```

## 中文

### 更新内容

### 新功能

- 新增自动吸边：悬浮球拖到屏幕边缘并松开后立即半隐藏，无需等待闲置。
- 新增界面语言自动检测，并支持简体中文、English、日本語和한국어；语言选择会被保存。
- 新增中、英、日、韩四语 README。

### 修复与优化

- 修复 Windows 悬浮球单击无响应、只显示拖动抓手的问题，并加入真实点击回归验证。
- 优化语言选择器的对齐、宽度和菜单配色，提高 Windows 下的文字可读性。
- 改进 Cursor 兼容模式、CLI 重新检测及多语言界面文案。
- 完善 macOS Universal 与 Windows Portable 构建流程，移除 sccache 构建依赖并修复 pnpm workspace 配置。

### 下载

- `Metra_0.1.38_universal.dmg`：macOS Universal，支持 Apple Silicon 与 Intel。
- `Metra-0.1.38-portable.exe`：Windows x64 便携版。
