# Metra v0.6.0

## English

Metra's desktop interface now uses GPUI and GPUI Kit. The application no longer
requires a WebView runtime. Existing provider collection, SQLite settings and
signed-update verification remain shared with the previous version.

- Keeps Cursor, Codex and Claude Code usage, quota windows, reset times, token
  totals, costs, stale-data fallback and Cursor compatibility consent/sign-in.
- Keeps floating-bubble and status-bar modes, provider labels/colors/order,
  visibility, used/remaining percentages, refresh intervals and startup options.
- Keeps edge docking, compact capsules, hover expansion, drag positioning,
  single-instance activation and background operation after closing a panel.
- Preserves existing settings and restores saved display positions. Includes
  seven interface languages and localized dates, numbers and currencies.
- Keeps Windows silent upgrades and portable builds, macOS DMG packaging,
  Linux Debian packages, and the independent Omarchy/JSON collector integration.

Download the asset for your system. On Windows, use the setup executable to
upgrade an installed copy or the portable executable for standalone use. On
Linux, install the Debian package on an X11/XWayland desktop with a Vulkan driver.
On macOS, open the DMG and move Metra into Applications. After moving the app,
**before the first launch**, remove the quarantine flag:

```sh
sudo xattr -dr com.apple.quarantine /Applications/Metra.app
```

## 中文

Metra 桌面界面现已改用 GPUI 和 GPUI Kit，不再需要 WebView 运行时。
用量采集、SQLite 设置及签名更新校验继续复用原有实现。

- 保留 Cursor、Codex 和 Claude Code 用量、各额度窗口、重置时间、Token
  总量、费用、过期数据回退，以及 Cursor 兼容模式授权和登录。
- 保留悬浮气泡和状态栏模式、提供商简称/颜色/排序/显隐、已用/剩余百分比、
  刷新间隔及开机启动设置。
- 保留贴边收起、胶囊悬停展开、拖动定位、单实例唤起，以及关闭面板后后台常驻。
- 兼容已有设置并恢复保存的显示器位置，保留七种界面语言及本地化日期、数字和货币。
- 保留 Windows 静默升级及便携版、macOS DMG、Linux Debian 安装包，
  以及独立的 Omarchy/JSON 采集集成。

请下载对应系统的文件。Windows 已安装用户使用安装程序升级，也可单独使用便携版。
Linux 请在具备 Vulkan 驱动的 X11/XWayland 桌面安装 Debian 包。
macOS 请打开 DMG，将 Metra 移入 Applications 后、**首次启动前**执行以下命令移除隔离标记：

```sh
sudo xattr -dr com.apple.quarantine /Applications/Metra.app
```
