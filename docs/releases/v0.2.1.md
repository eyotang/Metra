# Metra 0.2.1

## English

<!-- metra-unsigned-macos-notice -->
> [!WARNING]
> **macOS:** The Universal DMG is currently unsigned and not notarized. It is offered only as a manual download, is excluded from `latest.json`, and may trigger Gatekeeper. Verify the accompanying `.sha256` file before installation. After copying `Metra.app` to `/Applications`, run `sudo xattr -dr com.apple.quarantine /Applications/Metra.app` if macOS blocks launch.

**Windows:** Only the NSIS installer uses the signed Tauri updater. The Portable EXE detects updates but must be replaced manually.

**Linux:** The x86_64 Debian package supports Ubuntu with X11/XWayland. Verify its accompanying `.sha256` file and install or upgrade it manually; Linux in-app updates are not enabled.

## 中文

> [!WARNING]
> **macOS：** 此版本的通用 DMG 未进行开发者签名与公证，仅供手动下载，不包含在 `latest.json` 中，可能触发 Gatekeeper。安装前请核对随附 `.sha256` 文件。

### macOS 安装

将 Metra.app 移入 Applications 后，执行以下命令递归移除隔离标记：

```sh
sudo xattr -dr com.apple.quarantine /Applications/Metra.app
```

**Windows：** 仅 NSIS 安装版使用带签名的 Tauri 更新器；便携 EXE 可以检测更新，但需手动替换。

**Linux：** x86_64 Debian 包支持 Ubuntu 的 X11/XWayland。核对随附 `.sha256` 后手动安装或升级；不支持 Linux 应用内更新。
