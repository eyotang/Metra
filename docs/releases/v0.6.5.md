# Metra v0.6.5

## English

- On Windows, body text, buttons and usage figures use heavier font weights. Percentages in the floating bubble are bolder, and the full `100%` label fits in both bubble sizes.
- On Windows, the Chinese, Japanese and Korean interfaces now prefer Microsoft YaHei UI, Yu Gothic UI and Malgun Gothic respectively when those fonts are installed.
- The macOS release workflow can now reuse the Developer ID Application certificate from the Tauri version. This release uses an ad hoc signature, so macOS may ask for Keychain access again when you replace the app.

On macOS, move Metra to Applications. Before the first launch, run this command to remove the quarantine attribute.

```sh
sudo xattr -dr com.apple.quarantine /Applications/Metra.app
```

## 中文

- Windows 版加粗了正文、按钮和用量数字。悬浮球里的百分比也更醒目，展开和收起时都能完整显示 `100%`。
- Windows 版的中文、日文和韩文界面会优先使用已安装的对应系统字体，分别为微软雅黑 UI（Microsoft YaHei UI）、Yu Gothic UI 和 Malgun Gothic。
- macOS 发布流程现已支持复用 Tauri 版的 Developer ID Application 证书。本版仍采用临时签名，覆盖安装后，macOS 可能再次要求授权访问钥匙串。

在 macOS 上，将 Metra 移入“应用程序”后、首次启动前执行以下命令，移除隔离标记。

```sh
sudo xattr -dr com.apple.quarantine /Applications/Metra.app
```
