# Metra 0.5.17

## English

- Reapply the floating bubble size before its first appearance to address Windows startup showing a stretched capsule until the pointer moves over it.
- Add a native startup size check before hover and display-mode interactions.

### Windows x64

Run the installer to upgrade, or use the portable EXE with WebView2 installed.

### macOS installation

Move Metra to Applications. Before launching it for the first time, run this command to remove the quarantine attribute:

```sh
sudo xattr -dr com.apple.quarantine /Applications/Metra.app
```

## 中文

- 在悬浮球首次显示前重新设置尺寸，修复 Windows 启动时显示为拉伸胶囊、鼠标移入后才恢复的问题。
- 增加鼠标交互和显示模式切换前的原生启动尺寸检查。

### Windows x64

运行安装包即可升级，也可使用便携 EXE，需已安装 WebView2。

