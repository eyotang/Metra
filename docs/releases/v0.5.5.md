# Metra 0.5.5

- 恢复设置页可见的拖动把手，使用本地打包的 SortableJS。移除上下点击按钮，保留聚焦把手后用方向键排序。
- 拖动时显示紧凑的标题预览，其他服务平滑让位，并显示落位占位区域；输入框、颜色和显示开关不会启动拖动。
- 松手后保存排序；支持 Esc 取消、反向拖回、保存失败恢复和减少动态效果。后台更新不会打断拖动或丢失未完成的标签编辑。
- 保留 0.5.4 的全平台实色界面和平滑轮廓，状态栏、吸边及逐产品刷新动画不变。

---

Restore visible drag handles in provider settings using locally bundled SortableJS. Replace up/down click buttons with handle dragging and arrow-key access.

Use a compact title preview, animated live placement and a clear placeholder. Inputs, colors and visibility controls do not initiate dragging. Save on release, cancel with Escape, and restore the previous order if saving fails. Support repeated reverse moves and reduced motion while retaining unfinished label edits.

Keep the opaque surfaces and antialiased outlines from 0.5.4, along with status-bar behavior, edge docking and provider refresh feedback.
