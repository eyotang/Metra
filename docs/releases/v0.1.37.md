# Metra 0.1.37

## English

### Changes

- Add Claude API key usage display.
- Add optional edge docking and idle collapse for the bubble.
- Fix dragging and docking interactions.
- Provide Windows x64 portable and macOS Universal builds for Intel and Apple Silicon.

### Signing

> [!WARNING]
> The macOS app/DMG is not Developer ID signed or Apple-notarized. Windows executables are not Authenticode signed. Gatekeeper or SmartScreen may block or warn on launch. Download only from this GitHub Release and verify the SHA-256 checksums.

### macOS installation

Copy Metra.app to Applications, then run this command to remove the quarantine attribute recursively:

```sh
sudo xattr -dr com.apple.quarantine /Applications/Metra.app
```
