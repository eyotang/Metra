# Metra v0.6.3

## English

- Removes the tooltip that covered usage values when the pointer rested on the floating bubble.
- Uses heavier Inter text and larger numbers. The docked capsule adjusts the size of `100%` to keep every character visible.
- Restores the docked capsule after the pointer leaves on Linux X11.

On macOS, move Metra to Applications. Before the first launch, remove the quarantine attribute:

```sh
sudo xattr -dr com.apple.quarantine /Applications/Metra.app
```

## 中文

- 移除鼠标停留时遮挡悬浮球用量的提示浮层。
- 加粗 Inter 字体并放大数字。贴边胶囊会调整 `100%` 的字号，确保四个字符完整显示。
- 修复 Linux X11 上鼠标移开后，贴边胶囊未收回的问题。

在 macOS 上，将 Metra 移入 Applications 后、首次启动前执行以下命令移除隔离标记：

```sh
sudo xattr -dr com.apple.quarantine /Applications/Metra.app
```
