# Metra 0.5.12

## English

- Add complete French, German and Russian translations, expanding Metra to seven languages. Support automatic system-language detection, live language switching and saved language preferences.
- Add French, German and Russian README files and full language navigation across all seven README versions.
- Document translation maintenance and release requirements in AGENTS.md: English first, Chinese second, and macOS xattr instructions in every release description.

### macOS installation

Move Metra to Applications, then run this command before the first launch to remove the quarantine attribute recursively:

```sh
sudo xattr -dr com.apple.quarantine /Applications/Metra.app
```

### macOS 安装

将 Metra 移入 Applications 后，首次启动前执行以下命令，递归移除隔离标记：

```sh
sudo xattr -dr com.apple.quarantine /Applications/Metra.app
```
