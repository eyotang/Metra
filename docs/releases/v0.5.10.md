# Metra 0.5.10

## English

Fix stale capsule values when a visible native overlay's webview reports the document as hidden. Rendering now follows native window visibility. Hidden windows still cache updates until shown, and unchanged bubble data does not trigger extra rendering. Add regression coverage for usage updates in a visible capsule whose document reports hidden.

### macOS installation

Copy Metra.app to Applications, then run this command to remove the quarantine attribute recursively:

```sh
sudo xattr -dr com.apple.quarantine /Applications/Metra.app
```

## 中文

- 修复胶囊态收到新用量后仍停留在旧数值的问题：渲染以原生窗口可见状态为准，避免页面隐藏状态拦截更新。
- 保留隐藏窗口暂停渲染、重新显示时更新最新数据，以及用量未变化时不重复渲染的行为。
- 新增胶囊可见但页面报告隐藏时的刷新回归测试。

### macOS 安装

将 Metra.app 移入 Applications 后，执行以下命令递归移除隔离标记：

```sh
sudo xattr -dr com.apple.quarantine /Applications/Metra.app
```
