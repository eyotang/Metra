# Metra v0.6.6

## English

When you choose **Check for updates** and Metra is up to date, the confirmation appears at the bottom of the usage panel and disappears after six seconds. If you check again, the new result gets a fresh six-second timer. Automatic checks stay quiet when Metra is up to date.

On macOS, move Metra to Applications. Before the first launch, run this command to remove the quarantine attribute.

```sh
sudo xattr -dr com.apple.quarantine /Applications/Metra.app
```

## 中文

在用量面板点击**检查更新**后，如果已经是最新版本，面板底部会显示“Metra 已是最新版本”，6 秒后自动消失。再次检查时，从收到新结果起重新计时。后台自动检查发现已经是最新版时不会弹出提示。

在 macOS 上，将 Metra 移入“应用程序”后、首次启动前执行以下命令，移除隔离标记。

```sh
sudo xattr -dr com.apple.quarantine /Applications/Metra.app
```
