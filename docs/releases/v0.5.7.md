# Metra 0.5.7

- 移除前端每 30 秒无条件绘制的定时器。隐藏的面板和悬浮球仅接收共享数据快照，不绘制；展示时直接使用已缓存的快照，不重新采集用量。
- 悬浮球仅在其显示的用量、标签、颜色、语言或吸边状态发生变化时绘制，无关的采集时间和更新状态不会触发绘制。
- Windows、macOS 和 Linux 通过原生窗口显示/隐藏通知控制绘制。面板每次打开时按当前时间计算重置提示；采集频率、刷新进度动画、设置拖动和系统代理更新机制保持原有行为。

---

Remove the unconditional 30-second frontend rendering timer. Hidden windows cache the shared usage snapshot and render when shown, without requesting a new collection. The bubble renders only when its displayed data or appearance changes.

Use native window visibility notifications across desktop platforms. Recompute reset hints when the panel renders. Preserve collection intervals, refresh progress, provider sorting and system-proxy update support.
