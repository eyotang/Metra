# Metra 0.5.4

- 移除 Windows、macOS 和 Linux 的全部系统毛玻璃、网页背景模糊和半透明主表面，统一使用实色面板与悬浮球。
- 删除 Windows 的 GDI 圆角硬裁剪，保留浏览器绘制的抗锯齿像素，避免圆球和面板边缘被切出台阶。圆球、32px 吸边胶囊和圆角面板继续保留。
- 增加 100%、125%、150%、200% 缩放下的实际像素检查，要求内部完全不透明、轮廓平滑且四角透明。Windows 原生验收还会切换桌面底色，检查窗口内部颜色不受背景影响。
- 保留状态栏图标、五秒轮播、逐产品刷新动画、标题版本号、现有配置和旧版静默升级。

---

Remove system glass, web backdrop blur and translucent primary surfaces on Windows, macOS and Linux. Use opaque panels and bubbles throughout.

Remove Windows GDI window regions that cut away browser-antialiased outline pixels. Preserve the floating bubble, 32px edge capsule and rounded panels. Pixel checks cover opaque interiors, transparent corners and smooth edges at 100%, 125%, 150% and 200% scaling. Native Windows acceptance also changes the desktop color to verify that application surfaces stay opaque.

Status icons, provider rotation, refresh animations, the header version, existing preferences and legacy silent upgrades are retained.
