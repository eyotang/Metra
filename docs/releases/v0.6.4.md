# Metra v0.6.4

## English

- Metra checks GitHub for updates as soon as it starts, then checks daily while it runs. If a check fails, Metra retries after five minutes.
- When an update is available, the floating bubble shows a yellow dot and the tray menu offers a shortcut to the update. The usage and settings panels show the new version and a compact download or install button.
- The native interface now uses six weights of the original Inter typeface. This restores the weight of headings, buttons, usage numbers and text in the floating bubble.

On macOS, move Metra to Applications. Before the first launch, run this command to remove the quarantine attribute.

```sh
sudo xattr -dr com.apple.quarantine /Applications/Metra.app
```

## 中文

- Metra 启动时立即在后台向 GitHub 检查更新，运行期间每天检查一次。检查失败后会在五分钟后重试。
- 发现新版时，悬浮球显示黄色圆点，托盘菜单提供更新入口。用量面板和设置页会显示新版本号，下载或安装按钮的宽度随文案调整。
- 原生界面采用原版 Inter 的六档字重，恢复标题、按钮、额度数字和悬浮球文字的粗细层次。

在 macOS 上，将 Metra 移入 Applications 后、首次启动前执行以下命令，移除隔离标记。

```sh
sudo xattr -dr com.apple.quarantine /Applications/Metra.app
```
