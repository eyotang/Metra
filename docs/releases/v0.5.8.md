# Metra 0.5.8

## English

Keep the existing compact capsule layout active whenever the native window is narrow, even before the asynchronous peek event arrives. Hide provider labels and keep percentage values fully visible. Preserve the expanded bubble layout, data-driven rendering and shared usage snapshot.

### macOS installation

Copy Metra.app to Applications, then run this command to remove the quarantine attribute recursively:

```sh
sudo xattr -dr com.apple.quarantine /Applications/Metra.app
```

## 中文

- 修复吸边胶囊窗口已经收窄、异步胶囊状态尚未同步时，字母标签仍显示并挤压百分比的问题。窄窗口直接应用既有胶囊布局，保证只显示完整的百分比。
- 保留普通悬浮球展开后的标签布局、按需绘制、共享数据快照和现有交互。

### macOS 安装

将 Metra.app 移入 Applications 后，执行以下命令递归移除隔离标记：

```sh
sudo xattr -dr com.apple.quarantine /Applications/Metra.app
```
