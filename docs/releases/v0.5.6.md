# Metra 0.5.6

- 修复更新请求没有读取操作系统代理配置，导致已配置系统代理时仍然直连 GitHub 并超时的问题。更新检查及 Windows 安装包下载统一使用网络库提供的系统代理支持。
- 沿用原有官方更新地址、启动约 20 秒及每 24 小时的检查时机、版本比较和 Windows 签名校验。
- Windows 旧版升级验收改用保留的 v0.2.2 安装包，并继续验证已安装 v0.4.1 客户端使用的静默升级参数，避免依赖已撤下的发布包。
- 恢复成功检查的日志记录，增加可独立运行的实际更新地址联网验收。该验收已在同一系统代理环境下由失败转为通过。
