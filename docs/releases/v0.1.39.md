# Metra 0.1.39

## English

### Changes

- Add automatic version checks at startup and every 24 hours while running.
- Show detected updates for user-confirmed manual downloads from the matching GitHub Release page.
- Stay silent when GitHub is unreachable and retry at the next check interval.
- Fix and strengthen Windows bubble clicks, dragging and edge docking.
- Improve refresh animations and status display without affecting other UI elements.
- Extend automated PowerShell, UI and update-flow checks; improve future signing and release workflows.

Users of v0.1.38 must manually upgrade to v0.1.39 once because v0.1.38 has no update detection. This is a manual-download release. Once a later release provides a valid signed manifest, v0.1.39 can detect it automatically.

### Downloads

- `Metra_0.1.39_universal.dmg`: macOS Universal, Apple Silicon and Intel.
- `Metra-0.1.39-portable.exe`: Windows x64 portable.

### Signing

> [!WARNING]
> The macOS app/DMG is not Developer ID signed or Apple-notarized. Windows executables are not Authenticode signed. Gatekeeper or SmartScreen may block or warn on launch. Download only from this GitHub Release and verify the SHA-256 checksums.

### macOS installation

Copy Metra.app to Applications, then run this command to remove the quarantine attribute recursively:

```sh
sudo xattr -dr com.apple.quarantine /Applications/Metra.app
```

## 中文

### 更新内容

### 新功能

- 新增版本自动检测：启动后检查 GitHub Releases，持续运行时每 24 小时再次检查。
- 检测到新版本后会显示版本信息，由用户确认后再打开对应的 GitHub Release 页面手动下载。
- GitHub 暂时无法连接时保持静默，等待下一个检查周期，不持续弹错或反复重试。

### 修复与优化

- 修复并强化 Windows 悬浮球单击、拖动和吸边相关行为。
- 优化刷新动画与状态显示，避免刷新图标影响其他界面元素。
- 完善 Windows PowerShell、界面行为及更新流程的自动验证。
- 完善后续版本的更新签名和发布流程。

> 由于 v0.1.38 尚未包含更新检测功能，现有用户需要手动升级到 v0.1.39 一次。本次 v0.1.39 为手动下载发布；后续版本提供有效签名清单后，v0.1.39 将自动检测新版。

### 下载

- `Metra_0.1.39_universal.dmg`：macOS Universal，支持 Apple Silicon 与 Intel。
- `Metra-0.1.39-portable.exe`：Windows x64 便携版。

### 签名说明

> [!WARNING]
> 本次 macOS App/DMG 未进行 Apple Developer ID 签名与公证，Windows EXE 也未进行 Authenticode 签名。macOS Gatekeeper 或 Windows SmartScreen 可能阻止或警告运行。请只从本 GitHub Release 下载，并先核对下方 SHA-256。

### macOS 安装说明

打开 `Metra_0.1.39_universal.dmg`，将 `Metra.app` 拖入“应用程序”文件夹。

如果 macOS 因隔离属性阻止打开，请确认文件来自本 Release 并核对 SHA-256，然后执行：

```bash
sudo xattr -dr com.apple.quarantine /Applications/Metra.app
```

该命令只清除 `/Applications/Metra.app` 的隔离属性，不要把路径替换成更大的目录或使用通配符。
