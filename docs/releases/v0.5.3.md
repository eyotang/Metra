# Metra 0.5.3

- 修复 Windows 11 悬浮球、吸边胶囊和展开面板周围持续出现灰白矩形底色的问题。恢复早期 Tauri 版本的透明窗口路径，使用半透明面板；不再使用会填充透明四角的整窗 Acrylic/Blur 材质。
- 修复 macOS 状态栏图标在刷新和模式切换后失去系统模板属性、一直显示黑色的问题。图标随系统菜单栏外观调整，面板继续使用原生 HUD 毛玻璃。
- 新增原生回归检查：Windows 采集实际桌面合成截图，检查圆球、胶囊和面板的透明四角；macOS 检查更新前后状态栏图标的模板属性。

保留吸边、刷新动画、标题旁的版本号、状态栏轮播、现有配置与自动升级行为。

---

Fix persistent gray/white rectangles around the bubble, edge capsule and popup panel on Windows 11. Restore the transparent-window path used by earlier Tauri releases with translucent panels, avoiding whole-window Acrylic/Blur materials that fill transparent corners.

Keep the macOS status icon marked as a system template when refreshing or switching modes, allowing it to follow the menu bar appearance. macOS panels retain native HUD vibrancy.

Native regression checks now inspect actual composited Windows screenshots for clear corners and verify the macOS status icon template property after updates. Edge docking, refresh animations, the header version, status-bar rotation, existing preferences and automatic updates are retained.
