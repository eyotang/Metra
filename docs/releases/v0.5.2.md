# Metra 0.5.2

- 桌面界面迁移到 Tauri 2：Windows 使用 WebView2，macOS 使用 WKWebView，Linux 使用 WebKitGTK，移除 GPUI 渲染依赖。
- 通用控件使用本地打包的 Web Awesome，图标使用 Lucide。保留输入焦点、键盘操作、四种语言，以及标题旁的小号版本文字。
- 保留悬浮球和 32px 吸边胶囊、悬停展开、拖动定位，并修复 Windows 缩放或调整窗口尺寸后的圆角裁剪。
- 深色毛玻璃面板使用系统材质；macOS 系统状态栏及菜单跟随系统外观，Linux X11 恢复兼容合成器的原生模糊提示。
- 保留状态栏模式：macOS 文字用量、Windows 数字托盘图标、五秒轮播、服务排序与显示开关、已用/剩余百分比、自定义标签和颜色。刷新或打开面板不再重置轮播。
- 恢复各产品独立的刷新动画，检测完成后立即显示结果；顶部更新卡片固定在标题下方。
- 沿用原有 SQLite 配置、Cursor 兼容模式授权、采集器和 Omarchy JSON 协议。Windows 保留签名校验，并兼容旧版 `/S` 静默升级后的自动启动。

Windows 安装包会在缺少 WebView2 时引导安装；便携版需要系统已有 WebView2。macOS 通用 DMG 未经 Apple 公证，请核对随附 SHA-256。Linux 桌面包需要 WebKitGTK 4.1，悬浮窗口定位使用 X11/XWayland。

---

Metra now uses Tauri 2 instead of GPUI, with locally bundled Web Awesome controls and Lucide icons. This release preserves the floating bubble and edge capsule, native glass, four languages, per-provider refresh feedback, existing settings, collectors, Cursor consent and the Omarchy protocol.

Status-bar mode retains macOS usage text and Windows numeric tray icons, five-second provider rotation, ordering, visibility and used/remaining preferences. State updates no longer reset rotation. macOS system menus follow system appearance; Windows clipping updates after native resize/DPI changes. The update card stays below the header, and legacy Windows silent upgrades retain automatic restart after signature verification.

Windows installers bootstrap WebView2 when missing; portable builds require an installed WebView2 runtime. The macOS universal DMG is not notarized. Linux desktop builds require WebKitGTK 4.1 and positioned overlays require X11/XWayland.
