# Metra 0.4.1

- 恢复原版的顶部更新提示：更新卡片固定在标题下方、服务设置与用量列表之前，滚动列表时仍然可见。
- 恢复新版本标题、当前版本到新版本的提示及更新操作。Windows 安装版使用签名更新，其他发行方式打开对应发布页。
- 保留原有自动检查时机：启动约 20 秒后检查，之后每 24 小时检查。此修复包含 0.4.0 的毛玻璃、图标配色和 Cursor 用量兼容改进。

macOS 通用 DMG 使用临时签名，尚未经过 Apple 公证。请核对随附的 SHA-256 文件，将 `Metra.app` 拖入「应用程序」（`/Applications`）。确认下载来源后，如果 macOS 阻止启动，请在终端运行：

```sh
sudo xattr -d com.apple.quarantine /Applications/Metra.app
```
