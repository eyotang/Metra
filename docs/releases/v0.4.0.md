# Metra 0.4.0

Metra 0.4.0 将已验证的 0.3.1 版本升级为新的次版本，继续提供当前的 GPUI 原生界面及交互修复。

- 桌面界面使用 Rust、GPUI 与 GPUI-KIT，常用控件优先使用 GPUI-KIT 组件。
- 除系统状态栏外，应用窗口使用毛玻璃与半透明材质；清理外层白底，并让模糊表面匹配圆球、吸边胶囊及面板圆角。Linux 模糊效果取决于桌面合成器支持。
- 悬浮球仍为默认展示方式；状态栏模式、边缘吸附和已有设置继续保留。
- 服务列表支持通过左侧把手拖动排序及键盘上下调整，保存服务顺序、显隐、标签和预设颜色。
- 保留 Cursor、Codex、Claude Code 用量采集及独立 Omarchy 采集器。

Windows 安装版支持签名更新；Windows 便携版、macOS 和 Linux 使用发布页的对应文件手动更新。

macOS 通用 DMG 使用临时签名，尚未经过 Apple 公证。请核对随附的 SHA-256 文件，将 `Metra.app` 拖入「应用程序」（`/Applications`）。确认下载来源后，如果 macOS 阻止启动，请在终端运行：

```sh
sudo xattr -d com.apple.quarantine /Applications/Metra.app
```

---

Metra 0.4.0 promotes the verified 0.3.1 application to a new minor version. It retains the native Rust, GPUI and GPUI-KIT interface, frosted translucent windows, corrected overlay backgrounds, floating bubble and docked capsule, persisted status bar mode, provider drag handles and existing settings. Usage collectors and the standalone Omarchy integration remain available. Linux blur depends on compositor support.

Windows installers support signed updates. Portable Windows, macOS and Linux use manual downloads. The universal macOS DMG is ad-hoc signed and not notarized. Verify the accompanying SHA-256 file, copy `Metra.app` to `/Applications`, and use the `xattr` command above if macOS blocks launch.
