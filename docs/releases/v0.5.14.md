# Metra 0.5.14

## English

- Fix Cursor usage collection on macOS when Cursor stores its sign-in token with encrypted safe storage. Metra now reads the existing Cursor key directly through macOS Keychain services and decrypts the token in memory.
- Cache the token only in process memory to avoid repeated Keychain access on each refresh. Automatically replace the cache when Cursor changes its local token. If usage authentication fails, clear the cache and retry once; repeated rejection waits for a changed token instead of repeatedly requesting access.
- Add a persistent self-signed identity for local macOS builds: run `npm run setup:local-signing` once, then build and use `npm run install:local`. Local updates reuse the certificate and application identity. This local signing setup is separate from the downloadable release, which is not Developer ID signed or notarized; downloading another release may require authorization again.
- Update compatibility consent and local installation instructions across all seven languages. Credentials are never saved to disk or included in logs.

### macOS installation

Move Metra to Applications, then run this command before the first launch to remove the quarantine attribute:

```sh
sudo xattr -dr com.apple.quarantine /Applications/Metra.app
```

Cursor compatibility mode may ask for your login Keychain password. Select **Always Allow** if you want macOS to remember access for that signed application. In-memory caching reduces repeated access while Metra is running; a locked Keychain, changed authorization or changed signing identity can still require approval.

## 中文

- 修复 macOS 上 Cursor 将登录令牌加密存储后，Metra 无法获取用量的问题。通过 macOS 原生钥匙串接口读取现有 Cursor 密钥，并在内存中解密令牌。
- 令牌仅缓存在进程内存中，避免每次刷新重复访问钥匙串。Cursor 本地令牌变化时自动更新缓存；用量认证失效时清除缓存并最多重试一次，连续失败后等待令牌变化，避免反复请求授权。
- 为 macOS 本地构建增加持久自签名身份：首次运行 `npm run setup:local-signing`，之后构建并执行 `npm run install:local`。本地更新复用同一证书和应用身份。此配置与下载版独立；下载版未使用 Developer ID 签名或公证，更换下载版本后仍可能需要重新授权。
- 同步更新全部七种语言的兼容模式授权说明与本地安装指引。凭据不会保存到磁盘或写入日志。

### macOS 安装

将 Metra 移入 Applications 后，首次启动前执行以下命令，移除隔离标记：

```sh
sudo xattr -dr com.apple.quarantine /Applications/Metra.app
```

Cursor 兼容模式可能要求输入登录钥匙串密码。如需 macOS 记住对此签名应用的授权，请选择“始终允许”。内存缓存会减少 Metra 运行期间的重复访问；钥匙串锁定、授权变化或签名身份变化时，仍可能需要再次授权。
