# Metra v0.6.1

## English

- The app checks GitHub Releases directly. Installed Windows x64 copies verify the installer signature before applying an update. Windows portable, macOS and Linux open the release page for manual installation.
- Settings let you drop a provider before or after another provider, preview the insertion point, and choose from the original color presets. Keyboard ordering remains available.
- Each provider shows its own progress while refreshing. Quota percentages and reset countdowns use the same rounding as v0.5.18. Free bubble placement stays inside the display's work area, and the status-bar panel opens on the tray icon's display when the system reports its location.

On macOS, move Metra to Applications. Before the first launch, remove the quarantine attribute:

```sh
sudo xattr -dr com.apple.quarantine /Applications/Metra.app
```

## 中文

- Metra 直接查询 GitHub Releases。Windows x64 安装版在更新前验证安装包签名。Windows 便携版、macOS 和 Linux 会打开发布页供手动安装。
- 设置支持把提供商拖到目标项之前或之后，预览插入位置，并从原有预设中选色。仍可用方向键排序。
- 每个提供商独立显示刷新进度，额度百分比和重置倒计时沿用 v0.5.18 的取整规则。自由拖动悬浮球后会将其限制在屏幕可用区域内。系统提供托盘图标位置时，状态栏面板会在托盘所在的屏幕打开。

在 macOS 上，将 Metra 移入 Applications 后、首次启动前执行以下命令移除隔离标记：

```sh
sudo xattr -dr com.apple.quarantine /Applications/Metra.app
```
