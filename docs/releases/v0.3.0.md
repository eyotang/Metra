# Metra 0.3.0

Metra 的桌面界面已迁移至 Rust、GPUI 与 GPUI-KIT，恢复原版紧凑的深色面板、字体、水位图标及紫色选中态。

- 默认保留悬浮球，支持拖动、边缘吸附和半隐藏。
- Windows、macOS、Linux 新增可保存的状态栏展示方式，重启后恢复选择；状态栏每 5 秒轮播已启用服务。
- 保留 Cursor、Codex、Claude Code 的用量采集，以及已有 SQLite 设置、语言、服务顺序、颜色和显隐配置。
- Omarchy 继续使用原有 JSON 接口，发布包使用不依赖桌面界面的独立采集器。
- 更新构建、打包和签名流程，Windows 安装版继续验证已有更新签名。

Windows 安装版支持用户确认后的签名更新；Windows 便携版、macOS 和 Linux 通过对应 Release 资产手动更新。macOS DMG 使用临时签名，未经过 Apple 公证，请核对随附的 SHA-256 文件。

将 `Metra.app` 拖入「应用程序」（`/Applications`）后，如果 macOS 阻止启动，请在确认下载来源并核对随附的 SHA-256 文件后，在终端运行：

```sh
sudo xattr -d com.apple.quarantine /Applications/Metra.app
```

---

The desktop UI now runs natively with Rust, GPUI and GPUI-KIT. This release preserves the floating bubble as the default, adds a persisted status bar mode, retains existing SQLite settings and usage collectors, and ships a standalone Omarchy collector. Windows installers keep the existing signed update format; portable Windows, macOS and Linux use manual downloads. The macOS DMG is ad-hoc signed and not notarized.

After verifying the accompanying SHA-256 file, copy `Metra.app` to `/Applications`. If macOS blocks launch, run the `xattr` command shown above in Terminal.
