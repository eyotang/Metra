# Metra 0.3.1

- 除系统状态栏外，悬浮球、锁边胶囊、设置、详情及应用弹层统一使用原生毛玻璃与半透明材质；文字与功能控件保持清晰。
- 清理窗口外层底色，并让原生模糊表面匹配圆形、胶囊及面板圆角，避免底层背景从四角外露。
- 修复悬浮球鼠标移入、从锁边胶囊展开时出现深色圆角方形背景的问题；保持圆形悬浮球及原有吸附胶囊效果。
- 恢复服务列表左侧的拖动把手和键盘上下调整；支持拖到目标项之前或之后，并保存顺序。编辑标签不会触发排序。
- 优先使用 GPUI-KIT 的按钮组、列表项、颜色浮层及色块、滚动条，保留原有配色和 55 个预设颜色。
- 默认仍为悬浮球，状态栏展示方式及已有设置继续保留。

Windows 安装版继续支持签名更新；Windows 便携版、macOS 和 Linux 使用发布页的对应文件手动更新。

macOS 通用 DMG 使用临时签名，尚未经过 Apple 公证。请核对随附的 SHA-256 文件，将 `Metra.app` 拖入「应用程序」（`/Applications`）。确认下载来源后，如果 macOS 阻止启动，请在终端运行：

```sh
sudo xattr -d com.apple.quarantine /Applications/Metra.app
```

Use native frosted glass and translucent surfaces for application windows while retaining the system tray presentation. Fix the rectangular background behind the floating bubble while preserving its circular and docked capsule appearances. Restore the provider drag handle, before/after drop placement, keyboard reordering and saved order. Standard controls use GPUI-KIT components while retaining the existing preset palette and settings.

The universal macOS DMG is ad-hoc signed and not notarized. Verify the accompanying SHA-256 file, copy `Metra.app` to `/Applications`, and use the `xattr` command above if macOS blocks launch.

Linux blur is requested through the compositor; desktops without compatible blur support retain translucent surfaces.
