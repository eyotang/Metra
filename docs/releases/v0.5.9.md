# Metra 0.5.9

## English

Keep the Omarchy plugin manifest in sync with the application version during source installation and release packaging. Add CI coverage for stale source manifests and extracted release installations. Existing bar layout, usage interactions and other platforms' bubble behavior are preserved.

### macOS installation

Copy Metra.app to Applications, then run this command to remove the quarantine attribute recursively:

```sh
sudo xattr -dr com.apple.quarantine /Applications/Metra.app
```

## 中文

- 修复 Omarchy 状态栏插件清单一直显示 0.2.2 的问题。源码安装与发布打包统一读取 Cargo.toml 的应用版本，安装后显示正确版本。
- 加入源码版本一致性检查，以及源码安装、发布包安装的版本回归检查，避免后续发布再次遗漏。
- 保留现有状态栏布局、用量轮播与悬停面板，以及其他平台的悬浮球行为。

### macOS 安装

将 Metra.app 移入 Applications 后，执行以下命令递归移除隔离标记：

```sh
sudo xattr -dr com.apple.quarantine /Applications/Metra.app
```
