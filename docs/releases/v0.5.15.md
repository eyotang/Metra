# Metra 0.5.15

## English

- Prefer Cursor CLI sign-in credentials for usage collection, reducing dependence on the desktop app's encrypted storage format. Read the CLI's dedicated macOS Keychain item or its platform-specific auth file; skip expired tokens and fall back to the desktop sign-in when credentials are unavailable or usage authentication rejects them.
- On macOS, retain imported tokens in Metra's own Keychain item and process-memory cache. Bind each saved token to a SHA-256 fingerprint of the current local credential so it can be reused after restarting Metra without copying Cursor's decryption key.
- Remove stale cached credentials when the source changes, authentication fails, Cursor's desktop token is removed, or compatibility mode is disabled. Retry failed usage authentication once using the desktop path. Cache refused CLI Keychain reads for ten minutes to reduce repeated prompts.
- Update compatibility consent and README instructions in all seven languages. Imported credentials are protected by the system Keychain and are never written to settings files or logs. This release adds CLI credential discovery, not an independent browser sign-in.

### macOS installation

Move Metra to Applications, then run this command before the first launch to remove the quarantine attribute:

```sh
sudo xattr -dr com.apple.quarantine /Applications/Metra.app
```

The first credential import may ask for your login Keychain password. Select **Always Allow** to remember access for the signed application. The token can then be reused from Metra's own Keychain item after a restart. Credential changes, a locked Keychain, changed permissions or a changed signing identity can still require approval. Downloaded releases are not Developer ID signed or notarized; persistent local signing is available through `npm run setup:local-signing` and `npm run install:local`.

## 中文

- 用量采集优先复用 Cursor CLI 登录凭据，减少对桌面应用加密存储格式的依赖。读取 CLI 专用的 macOS 钥匙串条目或对应系统的登录文件；跳过过期令牌，凭据不可用或用量认证失败时回退到桌面端登录。
- 在 macOS 上，将导入的令牌保存到 Metra 自己的钥匙串条目，并保留进程内存缓存。使用当前本地凭据的 SHA-256 指纹绑定缓存，支持重启 Metra 后复用，不复制 Cursor 的解密密钥。
- 凭据来源变化、认证失效、Cursor 桌面令牌被移除或关闭兼容模式时清理旧缓存。用量认证失败时最多使用桌面端路径重试一次；CLI 钥匙串读取被拒绝后缓存十分钟，减少重复弹窗。
- 同步更新全部七种语言的授权说明和 README。导入的凭据由系统钥匙串保护，不写入设置文件或日志。本次增加 CLI 凭据发现，不包含独立浏览器登录。

### macOS 安装

将 Metra 移入 Applications 后，首次启动前执行以下命令，移除隔离标记：

```sh
sudo xattr -dr com.apple.quarantine /Applications/Metra.app
```

首次导入凭据可能要求输入登录钥匙串密码。选择“始终允许”可让系统记住对此签名应用的授权；之后重启 Metra 可从自己的钥匙串条目复用令牌。凭据变化、钥匙串锁定、权限变化或签名身份变化时，仍可能需要授权。下载版未使用 Developer ID 签名或公证；本机构建可通过 `npm run setup:local-signing` 和 `npm run install:local` 使用持久签名。
